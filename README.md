# mini_project_week6


EDA & Data Visualization Exercises

This repository contains the solutions for Day 26 to Day 30 activities from the course, focusing on exploratory data analysis (EDA), univariate/bivariate analysis, distributions, boxplots, groupby aggregation, and correlation analysis.

Structure

Day26_Distributions.ipynb – Load numeric dataset, plot histograms & KDEs, compute summary stats, apply log1p transformation on skewed features.

Day27_Histograms_Boxplots.ipynb – Plot histograms for numeric variables, boxplots by categorical group, compare group distributions.

Day28_Grouping_Aggregation.ipynb – Load dataset, perform groupby summaries for regions and segments, plot aggregated metrics.

Day29_Correlations.ipynb – Compute correlation matrices, plot heatmaps, scatter plots for strong/weak feature pairs.

Day30_EDA_Exercise.ipynb – Full EDA workflow: univariate & bivariate analysis, boxplots, groupby aggregation, correlation heatmaps, and actionable insights.
